# Security Policy

## Security Direction

Livechat Platform is designed as a trusted realtime communication platform.

The project follows defensive, legal, white-hat security principles only.

## Security Scope

Security areas include:

- secure authentication
- password hashing
- session protection
- account verification
- rate limiting
- CSRF protection
- XSS prevention
- authorization policies
- audit logs
- security events
- file upload safety
- API throttling
- webhook verification
- billing webhook protection
- incident evidence collection

## Hashing and Encryption

Passwords must be hashed.

Sensitive data that must be recoverable by the application may require encryption.

Message and media encryption must be introduced through a deliberate architecture decision.

## Responsible Disclosure

If you discover a security issue, do not publicly disclose it before it has been reviewed.

Please report security concerns privately to the project maintainer.
